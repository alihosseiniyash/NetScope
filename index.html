Allocation rules

Each requested network gets the smallest conventional IPv4 subnet (/30 or larger) with enough usable host addresses after rounding up growth and reserving an optional gateway IP. Allocation is aligned and sorted from largest to smallest. VLAN IDs are labels only; networking equipment must still be configured.

Core concepts

IP / network layer

Addressing, packet forwarding and routing between subnets.

MAC / data-link layer

Local-hop frame delivery over Ethernet and similar links.

TCP / UDP

Transport-layer ports and application flows; TCP provides ordered reliable delivery.

ARP / NDP

Resolve IPv4 or IPv6 next-hop neighbor link-layer information.

VLAN / subnet

A VLAN isolates Layer 2 broadcasts; an IP prefix defines Layer 3 addressing.

Routing

A more-specific prefix wins; the default route is 0.0.0.0/0.
